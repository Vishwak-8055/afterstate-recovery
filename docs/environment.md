# Environment variables

Generated by `scripts/gen_env_docs.py` from the `Settings` model. Every setting is prefixed `AFTERSTATE_`.

| Variable | Type | Default | Description |
|---|---|---|---|
| `AFTERSTATE_ENVIRONMENT` | `Literal` | `development` | development, test or production. Production refuses unsafe settings (insecure cookies, default DB credentials). |
| `AFTERSTATE_DATABASE_URL` | `str` | `postgresql+psycopg://afterstate:afterstate@localhost:5432/afterstate (rejected in production)` | SQLAlchemy URL of the platform metadata database (PostgreSQL). |
| `AFTERSTATE_ARTIFACT_DIR` | `Path` | `var/artifacts` | Where backups and run evidence are stored. Must be shared by API and worker. |
| `AFTERSTATE_SCRATCH_DIR` | `Path` | `/tmp/afterstate-scratch` | Where disposable restore environments are created. Keep the path short (unix socket limit) and give it plenty of disk. |
| `AFTERSTATE_MAX_ARTIFACT_BYTES` | `int` | `2147483648` | Largest backup accepted by upload and restore. |
| `AFTERSTATE_MAX_JSON_BODY_BYTES` | `int` | `1048576` | Largest JSON request body. |
| `AFTERSTATE_SESSION_TTL_SECONDS` | `int` | `43200` | Session lifetime. |
| `AFTERSTATE_SESSION_COOKIE_SECURE` | `bool` | `False` | Mark cookies Secure. Required in production. |
| `AFTERSTATE_ALLOW_REGISTRATION` | `bool` | `True` | Allow self-service sign-up. |
| `AFTERSTATE_ALLOWED_ORIGINS` | `list` | `PydanticUndefined` | JSON list of public origins allowed for CSRF origin checks and CORS. |
| `AFTERSTATE_RATE_LIMIT_AUTH_PER_MINUTE` | `int` | `10` | Sign-in and registration attempts per client IP per minute (per API process). |
| `AFTERSTATE_RATE_LIMIT_API_PER_MINUTE` | `int` | `600` | Requests per client IP per minute (per API process). |
| `AFTERSTATE_PG_BIN_DIR` | `pathlib.Path | None` | `auto` | Directory with PostgreSQL binaries; auto-detected when unset. |
| `AFTERSTATE_MAX_ENVIRONMENT_BYTES` | `int` | `8589934592` | Disk cap per restore environment; the restore is killed if exceeded. |
| `AFTERSTATE_DEFAULT_RESTORE_TIMEOUT_SECONDS` | `int` | `1800` | Default restore timeout for new projects. |
| `AFTERSTATE_DEFAULT_VALIDATION_TIMEOUT_SECONDS` | `int` | `600` | Default validation budget for new projects. |
| `AFTERSTATE_ENVIRONMENT_SHARED_BUFFERS_MB` | `int` | `128` | shared_buffers of each disposable cluster. |
| `AFTERSTATE_MAX_LOG_EVENTS_PER_RUN` | `int` | `3000` | Log events kept per run before truncation (full transcript stays in the evidence file). |
| `AFTERSTATE_WORKER_POLL_SECONDS` | `float` | `1.0` | Queue polling interval. |
| `AFTERSTATE_WORKER_LEASE_SECONDS` | `int` | `60` | Run lease; a run whose lease expires is recovered by the reaper. |
| `AFTERSTATE_WORKER_HEARTBEAT_SECONDS` | `float` | `10.0` | Lease heartbeat interval. |
| `AFTERSTATE_SCHEDULER_TICK_SECONDS` | `float` | `5.0` | Scheduler pass interval. |
| `AFTERSTATE_CLEANUP_RETRY_DELAY_SECONDS` | `int` | `30` | Delay before retrying a failed cleanup. |
| `AFTERSTATE_MAX_CONCURRENT_RUNS_DEFAULT` | `int` | `2` | Default per-workspace concurrency for new workspaces. |
| `AFTERSTATE_LAB_ENABLED` | `bool` | `True` | Enable the Recovery Lab. |
| `AFTERSTATE_FAULT_INJECTION_ENABLED` | `bool` | `True` | Honour faults on Recovery Lab runs (never on other runs). |
| `AFTERSTATE_WEBHOOK_ALLOW_PRIVATE_HOSTS` | `bool` | `False` | Allow webhooks to private addresses. Development only; refused in production. |
| `AFTERSTATE_LOG_LEVEL` | `str` | `INFO` | Log level. |
| `AFTERSTATE_LOG_JSON` | `bool` | `True` | Structured JSON logs. |
